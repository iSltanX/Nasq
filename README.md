# نَسَق

تطبيق عربي (macOS) بوضعين تحت عهد واحد — **لا يكتب عنك أبدًا**:

- **نَسَق** يرتّب النص ويجهّزه للنشر: الفقرات والمسافات والعناوين والترقيم وشكل العرض — لا تتغير كلمة.
- **شَذْب** يفحص الشذرة بعين محرّر: بطاقة قراءة وقصّات حذف مقترحة (اقتباسات حرفية من نصك) تقبل كلًّا منها أو ترفضها، وتحقق آلي يشهد أن لا كلمة أُضيفت.

يعمل محليًا بالكامل، ولا يُرسل أي نص إلا عند ضغط «نسّق النص» أو «افحص الشذرة» — ومستوى «تنظيف فقط» وتطبيق القصّات يعملان محليًا دون أي اتصال.

## التشغيل أثناء التطوير

```sh
npm run tauri dev
```

## بناء نسخة قابلة للتثبيت

```sh
npm run tauri build
```

النتيجة:
- التطبيق: `src-tauri/target/release/bundle/macos/Nasaq.app`
- ملف التثبيت: `src-tauri/target/release/bundle/dmg/Nasaq_7.0.0_aarch64.dmg`

انقل `Nasaq.app` إلى مجلد Applications أو افتح ملف `.dmg`.

## الإعدادات

من زر الإعدادات (أيقونة المنزلقات أعلى الواجهة) — تبويبان:
- **عام**: API Key وBase URL واسم النموذج.
- **المظهر**: أيقونة نَسَق (أربعة رموز من هوية `nasaq-brand`) وست عائلات لونية متمايزة لكل منها نسختها الليلية الخاصة — يُطبَّق المختار فورًا ويُحفَظ محليًا.

تُحفظ إعدادات الخدمة محليًا فقط في:
`~/Library/Application Support/com.nasaq.app/settings.json`

الافتراضي: Gemini عبر الواجهة المتوافقة مع OpenAI
(`https://generativelanguage.googleapis.com/v1beta/openai/` — النموذج `gemini-2.5-flash`).

## المسودات

زر «المسودات» في الشريط العلوي، و«حفظ كمسودة» فوق النتيجة.
تُحفظ المسودات (النص الأصلي والمنسّق والإعدادات المستخدمة) محليًا فقط في:
`~/Library/Application Support/com.nasaq.app/drafts.json`

## وضع شَذْب

المبدّل «نَسَق | شَذْب» في الشريط العلوي. في وضع شَذْب: «افحص الشذرة» يرسل النص مرة واحدة ويعيد بطاقة قراءة (الجملة المركزية، موضع الشرح الزائد، الخاتمة، الإيقاع) وقصّات مقترحة بحُمرة المصحّح — لكل قصّة سببها وعدد كلماتها وأثرها المتوقع ودرجة جرأتها، وزرا «احذف/أبقِ». الحذف يُطبَّق محليًا فورًا (لا نداء آخر)، وشريط الضمانة يشهد آليًا بعد كل قصّة: لم تُضف كلمة، وكل الناتج من نصّك. «أرسل إلى نَسَق» ينقل النص المشذَّب خامًا لوضع التنسيق كجلسة جديدة — وهو المعبر الوحيد بين الوضعين.

لإطفاء الوضع كليًا: من كونسول الويب نفّذ
`localStorage.setItem("nasaq-shadhb", "off")` ثم أعد فتح التطبيق — و«on» تعيده.
الإطفاء يخفي شَذْب كليًا: المبدّل، لوحة شَذْب، وشريط الفحص، وتبقى نَسَق وحدها
ظاهرة. (منذ v5.1 لا نَعِد بمطابقة حرفية لواجهة إصدار سابق — نَسَق نفسها تُصقل.)

## سجل الإصدارات

نظام الترقيم: **Major** (v5 → v6) لأي تغيّر واضح في تجربة الاستخدام أو وضعٍ/غرفةٍ جديدة؛ **Minor** (v5.1) لتحسينات داخل تجربة قائمة؛ **Patch** (v5.1.1) للإصلاحات الصغيرة.

### v7.0.0

هوية بصرية جديدة كاملة ونظام مظهر جديد — Major لأن تجربة الاستخدام تغيّرت بوضوح: أيقونات وشعار جديدان، عائلات لونية أعيد تصميم فلسفتها، ونظام وضعٍ يتبع النظام. (رقم 6.3.0 استُخدم أثناء التطوير ولم يُشحن قط — هذا أول إصدار يحمل كل ما يلي.)

- **اعتماد أصول `nasaq-brand` حصرًا**: «السطور» (الورقة المسطّرة والهامش ونقطة التصحيح — مرشَّح دليل هوية «المخطوطة الرقمية») هي أيقونة التطبيق وشعاره الافتراضيان. أيقونات الحزمة في `src-tauri/icons` من مولَّدات `AppIcon-Lines-Light`، وحُذفت الأصول القديمة كلها: `nasaq-mark*.svg` ومجلد `branding/` و`icon-source.png` — لا أصل بصري من خارج `nasaq-brand`.
- **رمز الشريط تكيفي ومبدّل أيقونة في «المظهر»**: الأيقونات الأربع (السطور، النون، النسيج، كلمة نسق) مضمّنة SVG بحبر `currentColor`، ونقطة التصحيح `#E23B2E` ثابتة بالبناء. الاختيار عبر `data-logo` يُحفَظ في `localStorage["nasaq-logo"]` ويُطبَّق مبكرًا منعًا للوميض، وأي قيمة مجهولة تُطبَّع إلى «السطور».
- **أيقونة دوك فعلية وقت التشغيل**: أمر Rust جديد `set_dock_icon` (`objc2-app-kit`: `NSApplication.setApplicationIconImage` على الخيط الرئيس) يبدّل صورة الدوك إلى التصميم المختار بنسخته الفاتحة/الداكنة حسب الوضع الفعّال، عند الإقلاع ومع كل تبديل — الصور الثماني مضمّنة في الثنائي (`src-tauri/icons/dock`، قالب أبل من `nasaq-brand`). أيقونة الحزمة في Finder/التطبيقات/Launchpad تبقى أيقونة البناء (حدّ منصة: لا إعادة كتابة لحزمة موقّعة).
- **ست عائلات لونية**: ورق نَسَق، نحاس، زيتون، حبر أزرق، ورد عتيق، رماد ناعم. نهارًا ورق القراءة واحد محايد (المظهر الفاتح الأصلي) وشخصية العائلة في اللهجات المضبوطة وحدها — الفعل الرئيس والعنوان وحلقة التركيز وصبغة التحويم والحالات المفعّلة؛ وليلًا لكل عائلة نسختها الكاملة الخاصة: امتداد داكن لهويتها لا سواد مشترك. ألوان الحالات (الخطأ والحُمرة والزيتوني) ثابتة عبر العائلات: حالة لا هوية. المعرّفات التقنية القديمة أُبقيت حفاظًا على الاختيار المحفوظ.
- **لوحة إعدادات محايدة معتمة في الوضعين**: رموز `--neutral-*` (نهارًا الورق الكريمي الأصلي، وليلًا فحمي لالوني `#212121/#191919`) لا تعرّفها كتل العائلات فلا يتسرب نحاس أو ورد أو زيتون أو أزرق إلى اللوحة وحقولها وبطاقات المعاينة وحبر أيقوناتها — العائلة داخلها في العيّنات وحدود المختار وعلامته والتبويب النشط وزر «حفظ» فقط. غشاء اللوحات فحمي محايد لا يُشتق من ظل العائلة.
- **نظام الوضع الجديد**: مبدّل شمس/قمر داخل «المظهر» هو أداة التحكم اليدوية الوحيدة (زر قمر الشريط أُزيل). قبل أول اختيار يدوي يتبع التطبيق مظهر النظام حيًّا (`prefers-color-scheme` مع مستمع `change`)، وبعده يثبت على المحفوظ في `localStorage["nasaq-appearance-choice"]`. المفتاح القديم `nasaq-appearance` كان يُكتب تلقائيًا كل إقلاع ففرض ليلًا بائتًا نجا حتى من إعادة التثبيت — يُتجاهل ويُمحى عند الإقلاع.
- **أمن واعتمادات**: ترقية `plist 1.9→1.10` تسحب `quick-xml 0.41` وتسد ثغرتين عاليتي الخطورة (RUSTSEC-2026-0194/0195)؛ `npm audit` صفر ثغرات؛ تدقيق كامل للأصول والمعرّفات والأنماط الميتة وحقن DOM وتسجيل الأسرار — نظيف. تحذيرات RUSTSEC الباقية كلها لحزم GTK الخاصة بلينكس ولا تدخل منتج macOS.
- **الخطوط والبنية كما هي**: Cairo للواجهة وAlmarai للمتن محليًا بلا CDN، والتكوين والمسافات ثابتة.
- الاختبارات: 93 في Node و48 في Rust كلها خضراء؛ تحقق متصفحي للحالات الاثنتي عشرة (٦ عائلات × وضعين)؛ وتحقق على الحزمة الحقيقية: اتباع النظام من حالة نظيفة، تنظيف المفتاح الموروث، ثبات الاختيار اليدوي والأيقونة بعد إعادة التشغيل، وتبديل الدوك الحي بالنسختين — بلقطات من الجهاز نفسه.
