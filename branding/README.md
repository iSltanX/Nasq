# هوية نَسَق البصرية

## الفكرة

الرمز تجريد لشذرة عربية قبل النشر: أسطر متفاوتة الطول محاذاة لليمين (اتجاه القراءة العربية)،
تُختم بنقطة معيّنة — وهي «نقطة الخطّاط»، وحدة القياس التي تُضبط بها نسب الحروف في الخط العربي.
النقطة هنا تحمل معنيين: الميزان والتناسب، وعلامة ختام النص الجاهز للنشر.
تفاوت أطوال الأسطر (طويل، قصير، متوسط، قصير) يصنع الإيقاع البصري الذي يقوم عليه التطبيق.

## الملفات

- `nasaq-appicon.svg` — أيقونة macOS الكاملة (شبكة 1024، جسم 824 بهوامش آبل، مع الظل)
- `nasaq-appicon-small.svg` — نسخة مبسّطة للأحجام 16/32 بكسل (ثلاثة أسطر أسمك ونقطة أكبر)
- `nasaq-mark.svg` — الرمز وحده بلا ظل، للواجهات والترويسات
- `nasaq-logo.svg` — الشعار الأفقي (الرمز يمينًا والاسم يساره)
- `Nasaq.icns` — ملف الأيقونة الجاهز لتطبيق macOS
- `AppIcon.iconset/` — مصدر الأحجام العشرة بأسماء آبل القياسية (لاستخدام Xcode مباشرة)
- `png/` — تصديرات PNG بخلفية شفافة

## ملاحظات استخدام

- كلمة «نَسَق» في الشعار مسارات SVG مرسومة، مستخرجة من خط **Almarai Bold**
  (Google Fonts، رخصة OFL — نفس عائلة خط التطبيق)، فلا تعتمد على خطوط النظام
  وتظهر متطابقة في كل العارضات والمنصات.
- الشعار مصمَّم لخلفية داكنة. على خلفية فاتحة استخدم الدرجة النحاسية الغامقة `#8F6A38` للنص والأسطر.
- لا تضف توهجًا أو ظلالًا إضافية على الرمز داخل الواجهة؛ النسخة `nasaq-mark.svg` مسطّحة عمدًا.
