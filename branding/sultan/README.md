# هوية سلطان البصرية · Sultan Visual Identity

نظام بصري شخصي متكامل لمطوّر برمجيات مستقل، مبني حول مخطوطة «سلطان» الأصلية ومحضّر للاستخدام في GitHub والتطبيقات المكتبية وإضافات المتصفح والتوثيق وملفات README وصفحات الإصدارات.

## سلامة المخطوطة

المصدر المحمي هو `assets/brand/source/sultan-calligraphy-original.svg`.

- SHA-256: `efcbccd1e1a9f779a0ac0d9523b2782472422aa7cb4facf0342b95d27fb2ab0b`
- لا تُعدّل بيانات المسار أو الانحناءات أو النسب.
- المسموح: التلوين، التحجيم المتناسب، والتموضع فقط.
- يتحقق `pnpm run check:identity` آليًا من تطابق بيانات المسار في جميع نسخ الشعار.

## التشغيل

```bash
pnpm install
pnpm dev
```

## البناء والتحقق

```bash
pnpm build
```

يشغّل البناء مولّد الأصول، ويفحص سلامة المخطوطة، وتباين الألوان، وأبعاد التصديرات، والخطوط المعتمدة، ثم يبني الدليل التفاعلي.

## البنية

```text
assets/   أصول SVG والتوكنز والقوالب
exports/  PNG وWebP ونسخ داكنة وفاتحة وشفافة
docs/     أدلة الاستخدام العملية
scripts/  توليد الأصول وفحوص سلامة الهوية
src/      الدليل التفاعلي
```

ابدأ من `docs/brand-guidelines.md` لفهم النظام، ومن `docs/asset-inventory.md` لاختيار الملف المناسب.
